# Triage 标签

各技能用五个标准 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 技能中的角色 | 本仓库实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定稿，可由 agent 独立实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |

当某个技能提到某个角色时（例如「打上 AFK 就绪的 triage 标签」），使用上表右列对应的标签字符串。

要改用别的词表时，直接改右列以匹配你实际使用的标签。
